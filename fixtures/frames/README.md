# fixtures/frames

`placeholder.jpg` is a generated drawing so tests run. **It is not a real photo.**

A human needs to drop real photos of the demo object here (JPEG, ideally the size the
app sends: 768 px on the long side, from the back camera). P2 uses them for the
YOLO-World accuracy check, so include a few angles and a few bad ones (blurry, dark).

Default scenario until the demo object is chosen: a bicycle rim brake with the pad
rubbing the rim.
